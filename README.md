# Motorcade

Adds customizable, buildable vehicles: assemble your own automobiles from frames, engines, wheels
and attachments, then drive them on roads, slopes and off-road terrain.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.249+
- [Vellumli](https://www.curseforge.com/minecraft/mc-mods/vellumli) (required, powers the in-game guide book)

## Installation

1. Download the JAR
2. Place it, along with Vellumli, in your `mods` folder
3. Launch the game

## In-Game Guide

Craft the Motorcade Guide book (found in the mod's creative tab) for a walkthrough of the build
loop, every part category, road/terrain blocks, and driving controls.
